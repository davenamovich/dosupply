NAME: request_mp4
DESC: AFTER a human has approved a preview, start rendering an MP4 of that temp page (25 credits = $0.25; BYOK: $0.01 with your own Railway worker saved, else the full $0.25; refunded on failure). Rendering takes 1–3 minutes. To avoid polling: pass callback_url (we POST the signed result when it finishes) and/or wait_seconds (hold this call open up to 100s and return the finished mp4Url inline; if it isn't done by then you still get the jobId for get_job_status (kind mp4)). Never render MP4s for unapproved previews.
SCHEMA: {
 "type": "object",
 "properties": {
  "pageUrl": {
   "type": "string",
   "description": "The approved pageUrl from generate_ad_creative / generate_multilanguage_ads."
  },
  "callback_url": {
   "type": "string",
   "description": "Optional https webhook. Receives the signed done/failed result; the response carries the webhook secret once."
  },
  "wait_seconds": {
   "type": "number",
   "description": "Optional, 0-100. Wait this long for the MP4 and return it in the same call."
  }
 },
 "required": [
  "pageUrl"
 ]
}
